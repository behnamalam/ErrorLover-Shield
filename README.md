## About

ErrorLover Shield is a security-focused tool that analyzes passwords,
detects weaknesses, estimates crack time, and provides recommendations
to create stronger and safer credentials.


## Features

- ✅ Password strength scoring
- ✅ Entropy calculation
- ✅ Crack time estimation
- ✅ Common password detection
- ✅ Weak pattern analysis
- ✅ Repeated character detection
- ✅ Password improvement suggestions
- ✅ CLI / GUI support
